# Acceptance Criteria — Project VEGA

Sign-off requires every line below to be demonstrable in the pre-production
environment.

| # | Criterion | Linked requirement |
|---|---|---|
| AC-1 | A new user creates an account with a corporate email and signs in via SSO | FR-1 |
| AC-2 | An unauthenticated visitor cannot reach any screen | FR-1 |
| AC-3 | The dashboard lists all 12 specified currency pairs | FR-2 |
| AC-4 | A rate change at the gateway is visible on screen within one second, with no page refresh | FR-3 |
| AC-5 | A threshold alert fires in-app and by email | FR-4 |
| AC-6 | Favourites survive a sign-out and sign-in | FR-5 |
| AC-7 | Every rate view appears in the audit log | FR-6 |
| AC-8 | Unit test line coverage is at or above 80% | Technical spec §5 |
| AC-9 | No rate data can be exported out of the application | Functional spec §4 |
