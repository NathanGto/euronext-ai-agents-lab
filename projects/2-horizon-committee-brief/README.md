# Project HORIZON · investor portal redesign

> Fiction, written for training. Nothing here is real Euronext material, and nothing produced
> from it is a real finding.

**The material.** The weekly minutes, the Jira status, the git activity, the scope and milestones, the risks and decisions.

**The job.** Build a 4 part committee brief, and cross-read the 3 sources against each other. Stories declared done in the minutes but still open in Jira, critical defects nobody mentioned, reported progress the activity does not support.

**Ready-made agent.** `committee-brief` is built for this project. Run it once as-is before you build your own.

Outputs go in `output/`, and the local app renders the newest one at
`http://localhost:3000`.

## Why this project exists

The current investor portal (v2) has a 22% drop-off rate on key institutional workflows and a Net Promoter Score of -14. Top-50 institutional clients have repeatedly requested a modern UX, real-time portfolio analytics, and mobile-first access. HORIZON v3 addresses these gaps and is a strategic priority for retention of high-value subscribers.
